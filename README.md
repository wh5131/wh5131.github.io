# 宝宝英语乐园

给 2～4 岁宝宝用的英文启蒙播放页。在开源项目 [BiliPicks](https://github.com/limin112/bilipicks)（MIT）的基础上改成了三岁英语启蒙清单：没有推荐算法，只播家长手选的视频。

- **成长路线**：6 关（儿歌与律动 → 字母 ABC → 数字和颜色 → 动物和身体 → 日常用语和礼貌 → 简单故事绘本），每关有一个亲子动手任务。
- **34 条视频**：每条 BV 号都通过 B 站公开接口核对过。优先收斑马儿歌、宝宝巴士官方的英文内容；海外经典儿歌和动画若无官方号，则使用来源可核对的搬运版，并标明原作。
- 播放器用的是 B 站官方嵌入播放器，不抓取视频流。

## 怎么打开

1. 用电脑双击 `index.html` 就能看，不需要安装，也不需要服务器。
2. 电视或投影仪请打开 `tv.html`。
3. 手机、平板也能用浏览器打开 `index.html`。如果要在另一台设备上打开，需要先把这个文件夹放到网上（例如 GitHub Pages、Cloudflare Pages），因为手机通常无法直接打开电脑里的本地文件。

进度只保存在这台设备的浏览器里，换设备或清除浏览数据会丢失。建议每次陪看 15～20 分钟，看完就停。如果点进 B 站，请关掉自动连播。

## 改内容

内容和原项目一样，都写在 `data.js` 里。可以用 `python3 update.py add ...` 添加新视频，或运行 `python3 update.py --check` 检查是否有失效视频。详细格式见上游仓库的说明。
